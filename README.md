# 転倒・フレイル予防アプリ

高齢の方が自宅で一人で行う、転倒予防のための筋力・バランス運動のアプリです。医師が決めたメニューを読み込み、見本のアニメと音声に合わせて運動し、記録を残します。

- 公開先：https://coldpeachtomato.github.io/Fall_prevention/
- 要件：[docs/requirements.md](docs/requirements.md)
- 作業の決まりと、これまでに決めたこと：[CLAUDE.md](CLAUDE.md)

最初の利用者は開発者の家族で、不特定多数への公開はしていません。

## できること

| 使う人 | できること |
| --- | --- |
| 本人 | 今日の運動（約30分の標準と、約10分の短い運動）、歩いた記録、これまでの記録を見る |
| 医師 | メニューの作成と変更、メニューを渡す（QR と A4 の印刷シート）、メニューの読み込み、記録の振り返り |

運動は23種類で、歩行を除く22種類に見本のアニメがあります。

## やらないこと

安全を保ち、医療機器に当たらない設計にとどめるための決まりです。

- サーバー、アカウント、ログインはありません。メニューと記録は、端末の中だけに保存します。
- 利用データを外部に送りません。解析ツールや広告もありません。
- レベル・支えの段階・回数を、アプリが自動で変えることはありません。変わるのは、医師が渡す新しいメニューを読み込んだときだけです。
- 転倒リスクや体の状態を、評価・判定・診断しません。
- カメラは、メニューの QR を読むためだけに使います。動きの測定やフォームの判定はしません。
- 病気の治療や予防の効果をうたう表現は使いません。

## 使い方

### はじめに（iPhone）

1. Safari で公開先を開きます。
2. 「共有」のボタンから「ホーム画面に追加」を選びます。
3. ホーム画面にできた「転倒予防」の印から開きます。

ホーム画面に追加しないで使うと、しばらく使わなかったときに、メニューや記録が消えることがあります。ホーム画面のアプリと Safari は保存場所が別なので、メニューはホーム画面から開いたアプリに入れてください。

初回の読み込みのあとは、通信がなくても動きます。新しい版を配置したあとは、アプリを一度開いて閉じ、もう一度開くと新しい版になります。

### 本人

1. ホームの「今日の運動を始める」を押します。
2. 体調と、まわり（靴、床、つかまる所、電話）を確かめます。当てはまる症状があるときや「今日は休む」を選んだときは、お休みとして記録します。
3. 見本のアニメと音声に合わせて運動します。種目の切り替えと休憩は自動で進みます。操作は「一時停止」と「中止」だけです。
4. 終わったら、きつさと、転んだこと・ヒヤリとしたことの有無を記録します。

### 医師

ホームのいちばん下の「医師用の設定」から入ります。暗証番号は `0101` です（本人の誤操作を防ぐためのもので、秘密を守る目的ではありません）。

- **メニューを変える**：種目、レベル、回数、支えの段階、強度の上限、歩行を決めます。保存の前に、いまのメニューとの違いを確かめます。
- **メニューを渡す**：QR と A4 の印刷シートを作ります。メニューに、氏名など個人を特定する情報は入りません。
- **メニューを読み込む**：アプリの中のカメラで QR を読むか、メニューコードを貼り付けます。iPhone のカメラアプリでは読み込めません。
- **これまでの記録を見る**：直近12週の実施状況、きつさ、転んだ・ヒヤリとした記録を見ます。

高リスクの種目は、メニューで明示的に選んだときだけ出ます。

## 開発

TypeScript（strict）、Vite、React、Canvas 2D（自前のキーフレーム補間）、IndexedDB、Service Worker の静的な PWA です。

```bash
npm install        # 依存パッケージの導入
npm run dev        # 開発サーバー
npm test           # 単体テスト（Vitest）
npm run build      # 型チェックとビルド（dist/）
npm run preview    # ビルド結果の確認（Service Worker も動く）
```

main に push すると、GitHub Actions（`.github/workflows/deploy.yml`）がテスト・ビルドを行い、GitHub Pages に配置します。

### ディレクトリ

```text
src/
  app/          画面の切り替え、セッションの手順、読み上げ、振り返りの集計
  screens/      各画面
  animation/    人物モデル、補間、描画、アニメの検査
  data/         運動データ（23種類）とキーフレーム（animations/）
  menu/         メニューの検証、メニューコード、QR、違いの一覧
  storage/      IndexedDB の読み書き
  safety/       開始前チェックと中止の目安の文言
tools/          キーフレームの生成スクリプト
docs/           要件メモ
```

### アニメ

- キーフレームは `src/data/animations/<id>.json` にあります。`tools/` の生成スクリプトで作り直せます。
- URL の末尾に `#preview` を付けると、開発用のプレビュー画面が開きます。コマ送り、関節の角度の変更、重心と支えの範囲の表示、JSON の書き出しができます。
- 登録した全アニメを、テストが確認チェックリストの計算できる項目（重心、足の滑り、可動域、速さ、字幕など）で検査します。
- 人が見本を確かめて「よい」としたアニメにだけ、確認済みの印（`checked`）を付けます。確認済みのアニメを後から変えたら、印を外して確かめ直します。

## まだ決まっていないこと

- 回数・秒数の初期値と値の範囲、きつさの5段階の言葉（医師の確定待ち）
- 運動の説明文（医師・理学療法士の確認待ち）
- 人物モデルの寸法・質量比・可動域の数値（原典との照合が済んでいません）
- 読み上げの声（端末の標準の声を使っています。録音音声への差し替えは未定）
- 記録の書き出し（バックアップ）を作るかどうか

## 使っているライブラリ

React、idb、qrcode-generator（QR の作成）、jsQR（QR の読み取り）、Vite、vite-plugin-pwa、Vitest。人物の絵、説明文は、すべてこのアプリのために作ったものです。
